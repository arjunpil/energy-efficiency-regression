# Energy Efficiency Regression Analysis

## Overview
A machine learning research project predicting heating and cooling load 
requirements of residential buildings using regression analysis.

## Dataset
UCI Energy Efficiency Dataset
- 768 building simulations
- 8 architectural features including relative compactness, 
  surface area, wall area, roof area, overall height, 
  orientation, glazing area, and glazing area distribution
- 2 target variables: Heating Load and Cooling Load

## Methodology
Implementing and comparing three regression models:
- Linear Regression
- Ridge Regression (L2 Regularization)
- Lasso Regression (L1 Regularization)

## Evaluation Metrics
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Technologies Used
- Python
- scikit-learn
- Pandas
- Matplotlib
- Seaborn
- Numpy
